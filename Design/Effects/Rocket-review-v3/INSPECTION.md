# Rocket inspection before revision 3

The active line-clear implementation is runtime-built by RoyalPowerupDirector from Resources/RoyalGameplay/EffectsRig.prefab. There is no separate RocketLineClear prefab. The rig is instantiated at scene root, with 32 pooled projectiles. Each projectile had a source-art half sprite, core and glow TrailRenderers, and one short fire mesh. Particle emitters are ordinary world-space ParticleSystems. The rig prefab has no board Mask/RectMask2D. Source images, scene, prefab and board scripts were hashed before editing.

Movement stopped at the last board cell plus 0.8 cell. It used an accelerating cubic curve. The glow lasted 0.42 seconds with a full-length taper; the 1.65-cell flame mesh moved with the head and left no sustained flame field. These explain the abrupt board-edge retirement and thin/empty cleared path.

CanvasGlobal is ScreenSpaceCamera, UI sorting layer (ID 58496801), order 2; it owns pause/menu dialogs. The UI layer sorts above Default. Level/Canvas is ScreenSpaceCamera order 1; its old header/bar are suppressed while the existing royal gameplay HUD is active. Board surface is Default order -1/2; rocket visuals use Default 32–38; fragments use Default 20. Header and booster layout is already independent of world VFX.

Revision 3 keeps the rig and main art unchanged. A dedicated unmasked child, GameplayVFX - unmasked rocket line clear, owns active rocket heads and custom particles. The existing HUD keeps its ScreenSpaceOverlay mode and sorting order 20, which render it above the world-space effects. The separate pause/menu Canvas keeps its existing UI sorting layer.
