## 7. What can and cannot be recovered

Readable and usable as design reference: object/prefab/sprite/audio/animation **names** and counts, scene object hierarchies by name, class composition, bundle names/sizes, level parameters for 01-50 (grid, moves, colors, goals, predefined cells, via the decoded FlatBuffers schema), item/goal/cell enums, and startup-related type/method names.
Recoverable only as inspection PNGs (already done for GameplayAtlas, HomeUiAtlas, UiAtlas, LevelWinAtlas, King, Sapphire, GameplayExtension): atlas textures. The Area01 4096x4096 atlas was not decoded.
Not recoverable in re-authorable form: MonoBehaviour fields and tuning (no type trees), animation curves and timing (AnimationClip data is binary; only names were read), animator state machines, shader source (56 shaders; names not readable), Spine rig data beyond raw `.skel` / `.atlas` bytes, particle-system parameters, TMP font assets, audio samples (in `resources.resource`), any script source (IL2CPP).
Legal boundary: all of the above is Dream Games' copyrighted work. None of it (names, textures, audio, Spine data, level bytes) may be imported into `Assets/`, shipped, or presented as importable. Names and parameters are used only to compare structure and behavior against the Royal Throne implementation.
