# Profile avatars in the reference's style — generation prompts

This is for **Nano Banana 2** on the Magnific website at **1k, 1:1**, where your Unlimited plan applies. Through Claude's
connection the same model costs 75 credits a run, and the balance there is 0.

Make **three runs**. Paste one prompt per run and attach **`style-reference-royal-match-avatar.png`** (in this folder) as
the reference image each time.

Each run gives one 2x2 sheet: four avatars drawn in the same pass, so they match. Each avatar comes out at 512 px, which
is the game's avatar size. Download the three sheets into this folder as `sheet-1`, `sheet-2` and `sheet-3` (any image
format). Claude will then split them, install the avatars, and check them in the game.

The order is fixed. The first ten keep the current avatar ids, so a player's saved choice carries over. Run 3's last two
are spares.

---

## Run 1

A 2x2 grid of four separate square profile avatars for a royal-themed match-3 mobile game, with thin, even gaps between
the four tiles. Use exactly the art style of the reference image: cute, chunky, toy-like 3D cartoon characters with big
round soft heads, tiny simple black dot eyes, rounded clay-like shapes, smooth glossy shading and bright saturated
colours. Each character is shown head and shoulders, centred and facing the viewer, on its own bright tile background with
a soft radial glow. The four characters are original, not copies of the reference:
- top left: a young queen with a golden crown with a blue gem, and auburn hair;
- top right: a brave little knight in rounded silver armour with a blue plume on his helmet;
- bottom left: a cheerful princess with brown skin, dark curly hair and a small pink tiara;
- bottom right: a court wizard with a big fluffy white beard and a tall purple hat with gold stars.
No text, no letters, no frames, no borders, no badges or icons.
