## 1. Findings that change the plan

Each finding is backed by the cited lines. Anything not verified is marked UNVERIFIED.

1. **`RoyalOfflineBuildPolicy.cs`: do not import it.** This differs from plan Task 3.5 Step 3.
   - It is an `IPreprocessBuildWithReport` (`Editor/RoyalOfflineBuildPolicy.cs:10`). It throws `BuildFailedException` whenever `UNITY_ADS` or `UNITY_INAPPS` is defined.
   - `main` defines `Standalone: UNITY_INAPPS;…;UNITY_ADS` and `Android/iPhone: UNITY_ADS` (`ProjectSettings.asset:851-855`). So it would fail every `StoryBuild` player build.
   - No imported file references it.
2. **`RoyalQaService` has no installer once the QA menu is dropped.**
   - The only code that creates it is `RoyalModMenu.OnScene` (`RoyalModMenu.cs:69-83`: `new GameObject("Mod Menu", typeof(RoyalQaService), typeof(RoyalQaMenu), typeof(RoyalModMenu))`). That file is not imported, because the QA mod-menu UI is out of scope.
   - Every suite that checks `RoyalQaService.Instance` would throw "Enter the game first". These include `PropellerV5Checks:24`, `ColorBallV4Checks:27`, `RoyalAllDualComboChecks:40` and the `qa.Practice()` callers.
   - **Resolution:** `PortChecks` (Task 4.0) creates `new GameObject("Port QA", typeof(RoyalQaService))` before a suite runs. It does this only in the Editor or a development build, and destroys it afterwards.
3. **`RoyalQaService` refuses to start a session on main.** `RoyalQaService.cs:68-70` returns with "QA requires the project's offline build configuration" under `UNITY_INAPPS || UNITY_ADS`. main defines both for Standalone. This confirms that the change in plan Task 3.5 Step 3 is needed for this file.
4. **`LevelManager.cs:506` and `:515` use `RoyalThrone.RoyalOfflineMode`.** This coupling is missing from the plan's list.
   - The two lines sit inside `#if FACEBOOK` and `#if UNITY_INAPPS`. main defines `UNITY_INAPPS` for Standalone, so line 515 compiles there.
   - `RoyalOfflineMode.cs` is not imported.
   - **Resolution:** use main's lines (`origin/main` `LevelManager.cs:472-486`).

   - `GUI/RoyalTextStyle.cs`;
