# Royal Tales: finalized name

**Decision: Royal Tales.** On 13 October 2026 the user explicitly finalized this name and requested backup of the Royal Throne logo, generation of the Royal Tales logo and animation, and replacement in the current game.

| Use | Wording |
| --- | --- |
| Game name | **Royal Tales** |
| Logo lettering | **ROYAL** / **TALES** |
| Descriptive store title | **Royal Tales: Match 3** |

This supersedes the 8 September Royal Throne decision. Keep the exact two-word spelling. This is a creative decision, not trademark clearance or a store reservation. Preliminary research found documented prior use of Royal Tales by FriendTimes; no external reservation, registration or publication is authorized by this branding task.

The royal castle, king, queen, gold crown and purple velvet identity remain the direction. Character, plot and other unadopted proposals remain proposals.

The original approved Royal Throne master remains at Design/Branding/royal-throne-splash-logo-v1.png. A dated backup of the master, runtime PNG, import metadata, naming brief and win-animation layers is at Design/Branding/Archive/Royal-Throne-2026-10-13/.

The new master is Design/Branding/royal-tales-splash-logo-v1.png; the runtime replacement uses the existing Assets/JellyGarden/Textures/menu/main_menu/logo.png path and sprite GUID. See the adjacent Royal Tales artwork record for animation and verification.

The development directory, namespaces, application identifiers, save keys and technical Unity product name are retained in this artwork task to preserve local progress and established references. A later build-label change must handle the Windows save identity before renaming that technical product setting. No Android rebuild or store release is included.

The authorized private backup repository remains jchakmaavian/jellygarden-codex. Earlier naming and creative documents are historical where they say Royal Throne; new branding uses Royal Tales.
