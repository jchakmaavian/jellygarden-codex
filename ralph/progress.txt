**Learnings for future iterations:**
  - A level cell's two digits take DISJOINT SquareTypes sets; LevelMakerEditor
    .SetType is the authority. An obstacle code in the block digit silently
    becomes a plain cell.
  - A BLOCKS target is not the board's block count (level 19: target 24, board
    56). Never rewrite it; only assert it is reachable.
  - Assembly-CSharp gets NUnit but not UnityEngine.TestTools, and an asmdef
    cannot reference a predefined assembly. Play-mode tests are unavailable;
    drive screens directly with a clock seam instead.
  - `System.Random` resolves into JellyGarden.Scripts.System; use global::.
  - Harvest templates from tools/shipped_levels, never Resources/Levels — after
    generation the latter holds the generator's own output.
