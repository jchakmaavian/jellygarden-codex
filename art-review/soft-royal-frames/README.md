# Soft Royal — five royal frames

Open `index.html` directly in a browser. Everything is local; no build or server is required.

These are five frame treatments for the selected **Soft Royal** level-start popup. The cream interior, goal, booster layout, and green Play button stay consistent so the frames can be compared directly.

| Design | Frame treatment |
| --- | --- |
| 01 · Gilded Silk | Slim rounded gold molding, an inner line, and tiny diamond corners |
| 02 · Sapphire Trim | Blue enamel, gold rails, cut corners, and gemstone clasps |
| 03 · Crown Crest | Sculpted crown, curled gold shoulders, and a small base ornament; recommended |
| 04 · Emerald Laurel | Green enamel, gold edges, and laurel branches at the corners |
| 05 · Palace Carving | Shaped gold molding, carved scrolls, and an emerald base ornament |

Select boosters, press Play for a local preview response, close and reopen the popup, or open a larger inspection. Hearts save a shortlist in this browser. The inspector supports Previous/Next, arrow keys, and Escape. The star gently floats and sparkles; the Motion control and reduced-motion preference disable animation.

## Validation

Checked in local headless Chrome at 1800 × 1100, 390 × 844, and 320 × 568. All five share identical content bounds. Frames and controls fit the phone canvas; assets and fonts load, with no JavaScript exceptions or horizontal page overflow. Verified booster selection and preview synchronization, Play feedback, close/reopen, cleared selections, saved shortlist persistence, inspector navigation, Escape dismissal, star animation, and reduced-motion handling.

Frames use inline SVG and CSS. Castle art, icons, boosters, star, and fonts are copies of the existing local mockup assets. This folder is a design exploration; game implementation follows the frame selection.
