# Gameplay redesign mockup v1

Approved visual proposal for King Leo, generated with the built-in image-generation tool and implemented in the gameplay UI. Actual Unity captures and generation records are in [implementation](implementation/README.md).

[Open the full gameplay mockup](gameplay-mockup.png)

- **HUD:** compact blue-and-gold target and moves panels, a crown crest, and a level badge.
- **Board:** a stepped 8×8 layout with recessed slate-blue cells, rounded edges, and a slim gold frame.
- **Match pieces:** red book, blue shield, green leaf, purple gem, gold coin, and crown, with distinct silhouettes and consistent glossy shading.
- **Power-ups:** horizontal rocket, TNT bundle, and a rainbow color bomb, shown inside the board.
- **Booster bar:** four large buttons for extra moves, glove, hammer, and bomb, with inventory badges. Pause is a separate control.

Reference: `art-review/board-border/level-3-393x852.png`, used for the existing castle setting and interface functions.
