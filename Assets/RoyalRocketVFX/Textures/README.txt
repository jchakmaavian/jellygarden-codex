No textures are required.

Every flame, star, ring, flash and smoke shape in this package is generated procedurally in
Shaders/RocketFire.shader, so the effect ships no particle sheets and redistributes no
third-party art. This folder is kept as the place to put your own textures if you extend the
shader with sampled art.

The only bitmaps in the package are the four directional rocket sprites in ../Sprites/.
