# Original project audio provenance

The six base clips are exact copies of the original Royal Throne Color Ball V2 sounds, created for this project in the preceding task. Their original source and generation provenance are preserved under `Assets/Boosters/ColorBall/V2/Audio/`.

`ColorBall_Orbit.wav` is derived locally from the project-owned `ColorBall_Charge.wav`: 950 Hz high-pass, 4800 Hz low-pass, short boundary fades, PCM16. No additional paid generation or reference-game audio was used for V3.

Live synchronization and mixing are implemented by ColorBallAudioV3. Required event names are exposed by ColorBallVisualV3. The reference comparison retains only the Royal Throne V3 audio track.
